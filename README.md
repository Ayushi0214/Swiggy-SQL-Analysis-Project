# Swiggy SQL Data Analysis

## Project Overview

An SQL-based data analysis project on Swiggy's dataset to uncover insights into customer behavior, restaurant performance, order trends, revenue, and delivery partner activity.

## Key Objectives

* Analyze customer ordering patterns and retention.
* Evaluate restaurant ratings and revenue.
* Identify order trends and delivery partner performance.
* Explore customer behavior across different cities and restaurants.

## SQL Concepts Used

* **Joins** – To combine data from multiple tables.
* **Common Table Expressions (CTEs)** – To simplify complex queries.
* **WHERE & HAVING** – To filter records and aggregated results.
* **GROUP BY** – To summarize data and identify trends.
* **Aggregate Functions** – COUNT, SUM, AVG, and others for analysis.
* **Date & Time Functions** – To analyze order trends and date-based patterns.
